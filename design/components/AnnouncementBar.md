# AnnouncementBar

Intentional addition (not on the live site): a slim dandelion strip above the header that names the next planting and links to it. It exists so the next date is visible on every page.

**Consumer provides:** the date and site from the next Plantings entry, and the link. The date shown in the preview is placeholder text.

- Night text on dandelion (11.9:1), `small` size, the link at weight 900.
- Hidden entirely when no planting is scheduled; never shows a past date.
- One line only. No close button.
