# PlantingCard

Intentional addition: one card per Plantings entry, built from the live Next planting typography. It's needed for the Plantings list and archive.

**Consumer provides:** a Plantings entry (date, time, site, one-line description, status) and the link. The dates and descriptions in the preview are placeholders.

| Variant | Use |
| --- | --- |
| `dc-planting` | Upcoming: `paper-sunk` ground, `dc-btn` to join. |
| `dc-planting dc-planting--past` | Held: `paper` ground, ghost button to the recap. Add trees planted once known. |

- 2px night outline, square corners. The tag uses `night` with `dandelion` text.
