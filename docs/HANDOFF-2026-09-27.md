## 5. Known environment note

In sandboxes with an older Chromium, 4 e2e checks on Dedicate and Donate fail only on number format ("R1,050" instead of "R1 050"), because the browser's `en-ZA` data differs. They pass in CI and with the pinned Playwright browsers. Don't change the format to suit an old browser.
